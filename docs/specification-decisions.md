# Identifier specification decisions

The key words "MUST", "MUST NOT", "REQUIRED", "SHALL", "SHALL NOT",
"SHOULD", "SHOULD NOT", "RECOMMENDED", "NOT RECOMMENDED", "MAY", and
"OPTIONAL" in this document are to be interpreted as described in BCP 14
[RFC2119] [RFC8174] when, and only when, they appear in all capitals, as
shown here.

This register governs observable UUID, ULID, TypeID, KSUID, and Nano ID
parsing, generation, and encoding choices. It does not claim that every
optional operation from each source is implemented. The
[conformance matrix](../specification/README.md), pinned sources, and
maintained-peer record define the verified boundary.
