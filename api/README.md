# API compatibility baselines

`v1/baseline.txt` is the immutable published-v1.0.0 API baseline.
`v2/baseline.txt` is the immutable published-v2.0.0 API baseline.
The active API gate compares `github.com/faustbrian/go-identifier/v2` with the
v2 baseline; released v1 remains represented separately and is not rewritten
by v2 work.
