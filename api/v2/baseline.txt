package identifier // import "github.com/faustbrian/go-identifier/v2"

Package identifier defines typed domain IDs and contracts shared by UUID, ULID,
TypeID, KSUID, and NanoID families. Start with Parse and a zero-value Validator,
or use a family package for generation and family-specific codecs.

The package does not coordinate uniqueness, authorize access, or supply
distributed idempotency. It starts no background work and requires no cgo or
service. Values may be read concurrently; callers must synchronize decoding into
a shared value. Validation and clock callbacks remain caller-owned.

CONSTANTS

const (
	// MaxTypedIDBytes bounds canonical text before a Validator is invoked.
	MaxTypedIDBytes = 1024
	// MaxTypedIDJSONBytes bounds an escaped JSON string before decoding.
	MaxTypedIDJSONBytes = MaxTypedIDBytes*6 + 2
)

VARIABLES

var (
	// ErrInvalid reports malformed, non-canonical, or disallowed input.
	ErrInvalid = errors.New("invalid identifier")
	// ErrEntropy reports an entropy read failure or an exhausted rejection budget.
	// Underlying reader errors are deliberately not retained in the error chain.
	ErrEntropy = errors.New("identifier entropy failure")
	// ErrClockRollback reports a clock moving behind supported generator state.
	ErrClockRollback = errors.New("identifier clock rollback")
	// ErrOverflow reports exhausted monotonic or sequence space.
	ErrOverflow = errors.New("identifier sequence overflow")
	// ErrUnsupported reports a valid but unsupported identifier feature.
	ErrUnsupported = errors.New("unsupported identifier")
)

TYPES

type Clock interface {
	// Now returns the current instant. It must not reenter the calling generator.
	Now() time.Time
}
    Clock supplies the time observed by a generator. Implementations need not be
    monotonic: time-ordered generators detect rollback at their time resolution.
    A clock shared outside one generator must provide its own synchronization.

type ClockFunc func() time.Time
    ClockFunc adapts a non-nil function to Clock without adding synchronization.

func (clock ClockFunc) Now() time.Time
    Now calls the underlying function.

type Family string
    Family identifies an encoding without implying equivalent guarantees.

	FamilyUUID Family = "uuid"

	// FamilyTypeID identifies TypeID values.
	FamilyTypeID Family = "typeid"
	// FamilyKSUID identifies Segment-compatible KSUID values.
	FamilyKSUID Family = "ksuid"

type Generator[T any] interface {
	// New returns a generated value or an error. Callers must not use the value
	// on failure; blocking and error classifications depend on the family.
	New() (T, error)
}
    Generator is the common generation entry point. It does not, by itself,
    promise concurrency safety, ordering, or uniqueness across instances;
    consumers must use the concrete generator's contract.

type ID[Tag Validator] struct {
	// Has unexported fields.
}
    ID is a strongly typed canonical identifier. Different Tag arguments are
    distinct Go types and cannot be mixed without an explicit conversion.
    Its zero value is unassigned. Text/binary/JSON marshaling allows that zero
    value, but parsing or decoding empty text rejects it; SQL NULL clears it.
    Unmarshal and Scan methods require a non-nil, exclusively owned receiver.

func Parse[Tag Validator](text string) (ID[Tag], error)
    Parse checks nonempty text and MaxTypedIDBytes before calling Tag's
    zero-value Validate method. It preserves accepted text without
    normalization. Failure returns the zero ID and an error wrapping ErrInvalid,
    not the validator error.

func (id ID[Tag]) Compare(other ID[Tag]) int
    Compare returns -1, 0, or 1 according to canonical lexical ordering.

func (id ID[Tag]) IsZero() bool
    IsZero reports whether no identifier has been assigned.

func (id ID[Tag]) LogValue() slog.Value
    LogValue redacts the identifier from structured logs. Callers must opt in
    explicitly with String when an identifier has been approved for logging.

func (id ID[Tag]) MarshalBinary() ([]byte, error)
    MarshalBinary uses canonical text so typed values remain family-neutral.

func (id ID[Tag]) MarshalJSON() ([]byte, error)
    MarshalJSON encodes text as a JSON string, including "" for an unassigned
    ID.

func (id ID[Tag]) MarshalText() ([]byte, error)
    MarshalText returns a new slice of canonical text, empty when unassigned.

func (id *ID[Tag]) Scan(src any) error
    Scan accepts strings or text byte slices through Parse; nil clears id.
    Other sources and invalid text return ErrInvalid without replacing id.
    Accepted bytes are not retained.

func (id ID[Tag]) String() string
    String returns canonical text.

func (id *ID[Tag]) UnmarshalBinary(data []byte) error
    UnmarshalBinary has the same validation and receiver semantics as
    UnmarshalText.

func (id *ID[Tag]) UnmarshalJSON(data []byte) error
    UnmarshalJSON decodes and validates a canonical JSON string no larger
    than MaxTypedIDJSONBytes. Empty strings and null are invalid. Errors wrap
    ErrInvalid and leave id unchanged; JSON parser diagnostics are not exposed.

func (id *ID[Tag]) UnmarshalText(text []byte) error
    UnmarshalText validates copied text through Parse and replaces id only on
    success.

func (id ID[Tag]) Value() (driver.Value, error)
    Value implements driver.Valuer. An unassigned ID is stored as SQL NULL.

type Inspection struct {
	// Family identifies the representation inspected, even for a zero value.
	Family Family
	// Version is the UUID version nibble for UUIDs or TypeID suffixes;
	// it is zero for families that do not define a UUID version.
	Version int
	// Timestamp is the embedded UTC instant, meaningful only when HasTime is true.
	Timestamp time.Time
	// HasTime reports whether this value exposes a recognized timestamp.
	HasTime bool
	// Sortable reports the family's ordering capability, not global issuance
	// order, uniqueness, or necessarily the presence of a timestamp.
	Sortable bool
}
    Inspection exposes only properties actually defined by an identifier family.

type Validator interface {
	// Validate returns nil only for accepted canonical text. Its error details
	// and cause are hidden behind ErrInvalid; panics are not recovered.
	Validate(string) error
}
    Validator validates the canonical text used by a typed ID. Implementations
    must be usable as their zero value so decoding never needs registration.
    Validate is called synchronously with bounded nonempty text; it must
    establish any family or domain policy that the tag requires. Concurrent
    parses may call it concurrently, so any state outside the zero-value tag
    must be synchronized.

package uuid // import "github.com/faustbrian/go-identifier/v2/uuid"

Package uuid implements the RFC 9562 UUID profile with strict lowercase parsing
and explicitly owned UUIDv4 and monotonic UUIDv7 generation. Start with Parse,
NewV4Generator, or NewV7Generator. SQL and pgx UUID codecs require no running
database; the package introduces no cgo or background work.

UUIDs are public identifiers, not credentials. Time-bearing UUIDs expose
timestamps, and per-generator monotonicity is not distributed uniqueness.
Strict text and generation policies are recorded as IDENTIFIER-UUID-DEC-001 and
IDENTIFIER-UUID-DEC-002 in docs/specification-decisions.md.

TYPES

type ID [16]byte
    ID is a UUID value copied by assignment. Callers can mutate their own array
    value; outbound encoding assumes it remains an assigned, valid UUID. Bytes
    returns a copy rather than an alias. Read-only methods may run concurrently
    if the array is not mutated. Decode methods require a non-nil receiver
    and exclusive access. The zero ID is unassigned; String formats its bits,
    but text/binary marshaling rejects it.

func FromBytes(value [16]byte) (ID, error)
    FromBytes copies and validates version 1 through 8 and the RFC
    variant. Invalid bytes return the zero ID and an error wrapping
    identifier.ErrInvalid.

func Parse(text string) (ID, error)
    Parse accepts only canonical lowercase RFC 9562 text and versions 1 through
    8 using the RFC variant. Nil/Max UUIDs, uppercase and alternate wrappers
    are deliberately outside this profile (IDENTIFIER-UUID-DEC-001; protected by
    TestParseRejectsNonCanonicalAndInvalidUUIDs). Failure returns a zero ID and
    an error wrapping identifier.ErrInvalid.

func (id ID) Bytes() [16]byte
    Bytes returns a copy of the 16-byte UUID.

func (id ID) Compare(other ID) int
    Compare returns -1, 0, or 1 according to unsigned binary ordering.

func (id ID) Inspect() identifier.Inspection
    Inspect extracts UTC timestamps for versions 1, 6, and 7 only. Sortable
    is true for versions 6 and 7; it does not establish generation order or
    validity for a caller-mutated array.

func (id ID) IsZero() bool
    IsZero reports whether no UUID has been assigned.

func (id ID) LogValue() slog.Value
    LogValue redacts the UUID from structured logs.

func (id ID) MarshalBinary() ([]byte, error)
    MarshalBinary returns a new 16-byte representation, or identifier.ErrInvalid
    when unassigned.

func (id ID) MarshalJSON() ([]byte, error)
    MarshalJSON encodes a UUID as a JSON string or an unassigned value as null.

func (id ID) MarshalText() ([]byte, error)
    MarshalText returns newly allocated canonical text, or identifier.ErrInvalid
    when unassigned.

func (id *ID) Scan(src any) error
    Scan accepts canonical strings, byte slices, or nil (SQL NULL). A 16-byte
    slice is interpreted as binary; other slices are text. Invalid input wraps
    identifier.ErrInvalid and leaves id unchanged; nil clears id. Bytes are
    copied.

func (id *ID) ScanUUID(value pgtype.UUID) error
    ScanUUID clears id for a pgx NULL; otherwise it validates and copies bytes.
    Invalid version/variant wraps identifier.ErrInvalid without replacing id.

func (id ID) String() string
    String returns canonical lowercase text.

func (id ID) UUIDValue() (pgtype.UUID, error)
    UUIDValue returns copied bytes for pgx, or an invalid pgtype.UUID (SQL NULL)
    when unassigned. It does not revalidate a caller-mutated array.

func (id *ID) UnmarshalBinary(data []byte) error
    UnmarshalBinary requires exactly 16 bytes and copies them on success.
    Invalid input wraps identifier.ErrInvalid and leaves id unchanged. UUID
    version and variant are validated by FromBytes.

func (id *ID) UnmarshalJSON(data []byte) error
    UnmarshalJSON parses a bounded JSON string, or clears id for the exact token
    null. Invalid input wraps identifier.ErrInvalid and leaves id unchanged.
    Encoded input is limited to 218 bytes, including quotes and escapes.

func (id *ID) UnmarshalText(text []byte) error
    UnmarshalText parses text and replaces id only on success. Invalid input
    wraps identifier.ErrInvalid; input bytes are not retained.

func (id ID) Value() (driver.Value, error)
    Value returns canonical text for database/sql, or nil (SQL NULL) when
    unassigned.

func (id ID) Version() int
    Version returns the RFC version nibble.

type V4Generator struct {
	// Has unexported fields.
}
    V4Generator generates UUIDv4 values and is safe for concurrent New calls
    when constructed with NewV4Generator. Each Read of a caller-provided reader
    is serialized; the concurrency-safe crypto/rand.Reader default is used
    directly. The zero value is not ready for use. The reader is borrowed,
    never closed; sharing it outside this generator requires caller-owned
    synchronization. A custom reader must not reenter this generator while its
    Read lock is held.

func NewV4Generator(entropy io.Reader) *V4Generator
    NewV4Generator constructs a random UUID generator. A nil reader selects
    crypto/rand.Reader for this generator instance.

func (generator *V4Generator) New() (ID, error)
    New reads 16 entropy bytes and sets the RFC 9562 section 5.4
    version/variant. Reader failures return a zero ID and identifier.ErrEntropy,
    hiding the cause. It can block on the reader and provides no cancellation or
    timeout.

type V7Generator struct {
	// Has unexported fields.
}
    V7Generator serializes New calls and owns the resulting monotonic sequence.
    Construct it with NewV7Generator; its zero value is not ready for use and
    it must not be copied after first use. Clock and entropy are borrowed,
    not closed. They run under the generator lock, must not reenter it,
    and need their own synchronization if shared outside this generator.
    No cross-instance or cross-process uniqueness is guaranteed.

func NewV7Generator(clock identifier.Clock, entropy io.Reader) *V7Generator
    NewV7Generator constructs a monotonic UUIDv7 generator. Nil inputs select a
    system clock and crypto/rand.Reader for this generator instance.

func (generator *V7Generator) New() (ID, error)
    New generates an RFC 9562 section 5.7 UUIDv7. A new millisecond reads
    fresh entropy; same-millisecond calls increment the 74-bit random field,
    revealing local issuance order. Invalid 48-bit Unix milliseconds,
    rollback, exhausted sequence space, and reader failures return a zero ID
    with identifier.ErrInvalid, ErrClockRollback, ErrOverflow, or ErrEntropy
    respectively. Failed calls do not advance the committed sequence,
    but may consume entropy. The clock and reader can block; New provides no
    cancellation or timeout.

package ulid // import "github.com/faustbrian/go-identifier/v2/ulid"

Package ulid implements the pinned ULID specification at revision
d0c7170df4517939e70129b4d6462cc162f2d5bf, with consistent-case parsing,
uppercase canonical output, and per-generator millisecond monotonicity. Start
with Parse or NewGenerator; StringLower supports existing lowercase storage.
The package requires no service or cgo and starts no background work.

ULIDs expose time and local issuance order, not distributed uniqueness or
authorization. Case and rollback policies are IDENTIFIER-ULID-DEC-001/002 in
docs/specification-decisions.md.

type Generator struct {
	// Has unexported fields.

    Construct it with NewGenerator; its zero value is not ready for use and it
    must not be copied after first use. Clock and entropy are borrowed, never
    closed. They run under the lock, must not reenter the generator, and need

package typeid // import "github.com/faustbrian/go-identifier/v2/typeid"

Package typeid implements TypeID specification 0.3.0 pinned at revision
be8ff0daf5dc1f6d40c62a03cfc89945263a69af. Start with Parse, FromUUID,
or NewGenerator. Parsing accepts every 128-bit suffix; generation uses UUIDv7.
The package requires no service or cgo and starts no background work.

Prefixes are application labels, not authorization boundaries. Values may
reveal creation time, and generators do not coordinate distributed uniqueness.
Parsing/zero semantics and generation are IDENTIFIER-TYPEID-DEC-001/002 in
docs/specification-decisions.md.

FUNCTIONS

func ValidatePrefix(prefix string) error
    ValidatePrefix accepts empty text or up to 63 lowercase ASCII letters and
    underscores, with a letter at each end. Consecutive interior underscores are
    valid. Invalid input wraps identifier.ErrInvalid.

type Generator struct {
	// Has unexported fields.

    Generator binds a prefix to a UUIDv7 generator. Concurrent New calls share
    the source's serialized sequence. Its zero value is not ready for use;

type ID struct {
	// Has unexported fields.

    ID is an immutable TypeID. Its Go zero value is the official unprefixed

func (id ID) LogValue() slog.Value

package nanoid // import "github.com/faustbrian/go-identifier/v2/nanoid"

Package nanoid implements the Nano ID reference profile pinned at revision
07a39d62d84c21af5046fe6b2ef7b3e36ee557db, restricted to unique printable
ASCII alphabets, bounded sizes, and a 120-bit ideal entropy floor. Start with
DefaultConfig and NewGenerator, or Parse for default text. Custom decoding
requires Prepare. The package requires no service or cgo and starts no
background work.

NanoIDs provide neither time order nor authorization. Randomness quality
depends on the supplied reader; the size floor alone cannot ensure uniqueness
or secrecy. IDENTIFIER-NANOID-DEC-001 in docs/specification-decisions.md records
the deliberate restrictions on the reference profile.

CONSTANTS

const (
	// DefaultAlphabet is the URL-safe alphabet used by the reference NanoID.
	DefaultAlphabet = "_-0123456789abcdefghijklmnopqrstuvwxyzABCDEFGHIJKLMNOPQRSTUVWXYZ"
	// DefaultSize is the reference NanoID length.
	DefaultSize = 21
	// MinimumEntropyBits prevents configurations below the package's security
	// floor. NanoIDs remain identifiers, not secrets or authorization evidence.
	MinimumEntropyBits = 120

TYPES

type Config struct {
	// Alphabet is an ordered set of 2 through 94 distinct printable ASCII bytes
	// (0x21 through 0x7e). Its order affects seeded generation, not uniformity.
	Alphabet string
	// Size is the output byte count, at most 1024 and large enough to provide
	// Size*log2(len(Alphabet)) >= MinimumEntropyBits of ideal entropy.
	Size int
}
    Config defines a copied alphabet and fixed byte length. The zero Config is
    invalid; use DefaultConfig or an explicitly validated custom configuration.

func DefaultConfig() Config
    DefaultConfig returns the 21-character URL-safe NanoID configuration.

func (config Config) Validate() error
    Validate rejects alphabets that could bias or ambiguously encode output
    and configurations below 120 bits of ideal entropy. Failure wraps
    identifier.ErrInvalid; no defaults are applied to an invalid Config.

type Generator struct {
	// Has unexported fields.
}
    Generator serializes New calls over a copied configuration and borrowed
    reader. Construct it with NewGenerator; its zero value is not ready for use
    and it must not be copied after first use. The reader is never closed and
    runs under the lock; it must not reenter the generator and needs its own
    synchronization if shared elsewhere.

func NewGenerator(config Config, entropy io.Reader) (*Generator, error)
    NewGenerator constructs a bias-free NanoID generator. A nil reader selects
    crypto/rand.Reader for this generator instance. Invalid configuration
    returns nil and identifier.ErrInvalid; caller-supplied entropy quality
    remains the caller's responsibility.

func (generator *Generator) New() (ID, error)
    New samples alphabet positions uniformly when entropy bytes are uniform.
    It allows at most 128 batches; read failure or rejection-budget exhaustion
    returns a zero ID with identifier.ErrEntropy and hides the reader's cause.
    Reads can still block without cancellation: the batch bound is not a
    deadline.

type ID struct {
	// Has unexported fields.
}
    ID is an immutable NanoID carrying the configuration required to validate
    subsequent decoding. Its zero value decodes with DefaultConfig. Read-only
    methods may run concurrently. Decode methods require a non-nil receiver and
    exclusive access; they leave it unchanged on invalid input.

func Parse(text string) (ID, error)

    Invalid text returns a zero ID with identifier.ErrInvalid.

    it. Invalid config returns a zero ID with identifier.ErrInvalid. JSON null

func (id ID) Compare(other ID) int
    Compare returns lexical ordering. NanoID generation itself is not sortable.

func (id ID) Config() Config
    Config returns the carried configuration by value, or DefaultConfig when no
    custom configuration has been assigned.

func (id ID) Inspect() identifier.Inspection
    Inspect reports that NanoIDs define neither time nor sortable generation.

func (id ID) IsZero() bool

func (id ID) LogValue() slog.Value
    LogValue redacts the NanoID from structured logs.

func (id ID) MarshalBinary() ([]byte, error)
    MarshalBinary returns a new text slice, with the same errors as MarshalText.

func (id ID) MarshalJSON() ([]byte, error)
    MarshalJSON encodes a NanoID string or null when unassigned.

func (id ID) MarshalText() ([]byte, error)
    MarshalText returns newly allocated text or identifier.ErrInvalid when
    unassigned.

func (id *ID) Scan(src any) error
    Scan validates strings or text byte slices against Config(). Nil clears text
    while preserving configuration. Invalid sources wrap identifier.ErrInvalid
    without changing id; accepted bytes are not retained.

func (id ID) String() string
    String returns the NanoID text.

func (id *ID) UnmarshalBinary(data []byte) error
    UnmarshalBinary uses UnmarshalText; bytes are text, not a separate raw

func (id *ID) UnmarshalJSON(data []byte) error

    retaining a prepared custom configuration. Encoded input is bounded to

func (id *ID) UnmarshalText(text []byte) error

    Value returns identifier text for database/sql, or nil (SQL NULL) when
    unassigned.

package idtest // import "github.com/faustbrian/go-identifier/v2/idtest"

Package idtest provides deterministic clocks, entropy, and reusable identifier
assertions. Its sources are for tests and must not be used for production
identifier generation. Start with NewClock and NewReader to inject reproducible
sources, then AssertUnique or AssertCanonical for contract checks. Sources are
concurrency-safe but concurrent scheduling can change which caller gets each
byte or instant. The package starts no background work and requires no service
or cgo; it does not simulate distributed uniqueness.

FUNCTIONS

func AssertCanonical[T stringValue](t testing.TB, value T, parse func(string) (T, error))
    AssertCanonical checks that parse(value.String()) yields an equal value
    using Go equality. Parse must be non-nil; failed diagnostics redact text and
    errors.

func AssertStrictlyOrdered[T any](t testing.TB, values []T, compare func(T, T) int)
    AssertStrictlyOrdered proves each adjacent value is greater than its
    predecessor under compare. Compare must be non-nil when there is an adjacent
    pair; zero or one value passes without invoking it.

func AssertUnique[T comparable](t testing.TB, generator identifier.Generator[T], count int) []T
    AssertUnique generates count values, fails on errors or collisions,
    and returns the generated sequence for additional assertions. Count must be
    nonnegative; generation is sequential and Go equality defines a collision.

func ErrorReader(err error) io.Reader
    ErrorReader returns a reader that always returns zero bytes and err without
    modifying the destination. Supply a non-nil error: nil would produce a
    non-progressing reader rather than a failure.
