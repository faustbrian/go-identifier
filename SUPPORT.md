# Support

Use GitHub issues for reproducible defects, documentation gaps, and bounded
feature proposals. Include the module path and version, Go version, platform,
minimal reproduction, expected behavior, actual behavior, and relevant
non-secret logs.

Use [GitHub issues](https://github.com/faustbrian/go-identifier/issues) for
adoption questions and bounded design exploration. Use the private process in
[`SECURITY.md`](SECURITY.md) for vulnerabilities.

Support covers released module versions according to
[`COMPATIBILITY.md`](COMPATIBILITY.md). The stable v1 module requires Go
1.26.6. Changes on `main` remain unreleased until included in a tagged version.
